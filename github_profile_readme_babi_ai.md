## 👨‍💻 About Me

I am **Abdelmomin Babi**, the builder behind **BABI.AI**. I specialize in designing end-to-end **data pipelines**, **AI-powered document intelligence**, and **deterministic risk & anomaly detection systems** that turn raw, unstructured business documents into clean, auditable, decision-ready data.

- 🔭 **Currently building:** Financial & procurement intelligence hubs under **BABI.AI**.
- 🧠 **Core interest:** Combining **LLMs (Google Gemini)** with **deterministic rule engines** and **Star Schema data warehouses** for reliable, production-grade automation.
- 🛠️ **Engineering philosophy:** Clean architecture, strict validation (`Pytest` & `Pydantic`), and zero-trust arithmetic verification.
- 🤝 **Open to:** Collaborations on AI automation, data engineering, and custom business intelligence tools.

## 🚀 Featured Project

### 📊 [Invoice Spend & Anomaly Intelligence Hub](https://github.com/babiabdealmomin-automation/invoice-anomaly-hub)

An end-to-end financial document intelligence and spend auditing platform designed for multi-language invoices (Arabic, French, English).

| Capability | Technical Implementation |
| :--- | :--- |
| **Native Document AI** | Direct PDF extraction via **Google Gemini File API** + batch `CSV` / `XLSX` ingestion with `SHA-256` deduplication. |
| **Deterministic Audit Engine** | Strict line-item & grand-total verification, historical `PRICE_SPIKE` detection, `NEAR_DUPLICATE`, `SPLIT_INVOICE_PATTERN`, `NIF/Bank` validation, and `HIGH_RISK` / `Offshore` fraud flags. |
| **Analytical Warehouse** | Modular **SQLAlchemy / SQLite Star Schema** (`dim_vendors`, `dim_dates`, `fact_invoices`, `fact_invoice_lines`). |
| **Interactive Control & Exports** | **Streamlit** dashboard with customizable risk rule weights, threshold controls, one-click warehouse reset, and clean `CSV` / `Excel` / `JSON` exports. |
